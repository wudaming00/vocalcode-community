Microsoft Visual C++ Runtime redistribution notice
=======================================================

VocalCode's Windows package distributes unmodified x64 retail CRT
runtime files from the GitHub-hosted runner's licensed Visual Studio installation:

  VC/Redist/MSVC/<version>/x64/Microsoft.VC*.CRT/*.dll

The packaged runtime-inventory.json lists the exact shipped filenames,
versions and SHA-256 hashes. Debug and non-redistributable directories are
not copied. Microsoft signatures are verified before bundling.
Copyright Microsoft Corporation.

Microsoft identifies files within the Visual Studio VC/Redist directory as
distributable code, subject to the Microsoft Software License Terms for the
licensed Visual Studio edition, and requires the files to remain unmodified.
The authoritative redistribution lists for the supported Visual Studio images are:

https://learn.microsoft.com/en-us/visualstudio/releases/2022/redistribution
