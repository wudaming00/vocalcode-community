# 本轮开发版：本机验收清单

这是手动验收清单，不是发布记录。五小时研究交付后，用户另行要求本机替换及缩小胶囊；最新行为见 [小胶囊细节修整](CAPSULE-FINISHING.zh-CN.md)，早期过程保留在 [小胶囊迭代](TINY-CAPSULE.zh-CN.md)。本机兼容构建保留原版数据身份，不是 Community 数据迁移。

## 先确认版本与环境

- 只有在你准备测试时才关闭当前运行的 VocalCode，再启动明确选定的测试构建。不要同时运行两个版本，以免它们竞争全局快捷键。
- Community 使用独立数据目录，不能因为新版本暂时看不到旧历史，就删除或覆盖原目录。模型准备、数据迁移和安装需要单独确认。
- 本轮常驻控制条仅 Windows，默认关闭；macOS 不宣称已实现或已验收。
- 先使用空白记事本 / 空白浏览器输入框；不要用终端命令行、密码框或真实聊天发送框测试。测试不需要按发送键。

## 桌面控制条（约两分钟）

在设置的录音指示器区域开启“桌面控制条”，可选择底部、左侧或右侧。

1. 空闲、录音和识别时均显示 48 × 18 的细胶囊（跟随 DPI / 文字缩放），不自动弹出大的 Listening / Working 提示。空闲或录音时悬停/点击胶囊只展开快捷控制，不录音；空闲时的“更多”需另点一次。把光标放在空白测试输入框，再点击展开后的麦克风开始；移开后应收回小波形，重新悬停可停止或取消。焦点应留在原输入框，完成后只输入一次，不发送消息。
2. 重复开始时快速双击：应只开始一次。录音中点击取消：本次不应继续追加结果；若已启用渐进输入，先前追加的文字不会被反向删除。
3. 检查原快捷键仍能工作。控制条免提模式不应改变下次快捷键的“按住 / 切换”偏好。
4. 空闲时悬停，点击“更多”后才能打开历史或设置、隐藏一小时；在设置中关闭再开启应找回控件。仅悬停不应出现完整菜单。
5. 空闲时进入全屏应用应隐藏；正在录音时仍需看到录音状态。多屏 / 不同缩放比例分别检查，留意控件展开时开始按钮是否移位。
6. 有意切换输入框，确认不会继续向未验证的目标输入；如有部分文字已经输入，先检查目标和历史再手动复制，避免重复。
7. 识别时胶囊保持小尺寸，只有轻微呼吸，不出现无效的“取消推理”。系统开启减少动态效果时应停止循环动画，但状态仍能通过颜色和无障碍名称区分。
8. 小胶囊可见时，不应再出现另一条旧录音提示。实际错误、文字找回提示仍可显示较宽说明；这不是正常录音时的 Listening 横条。

隐藏原生测试已覆盖窗口样式、布局和程序化 IPC，但这些步骤里的真实鼠标、触控与原生目标应用仍需要人工测试。

## 智能改写（可先不登录任何服务）

入口：历史记录 → “智能改写草稿 · 可选测试版”。也可以点击某条历史的“放入改写草稿”。这一步只载入本地草稿，不触发模型。

1. 点击“检测已安装的服务”。没有 Ollama / CLI 应明确显示不可用，不应自动安装、登录、下载模型或上传草稿。
2. 有本地 Ollama 模型时，选本地模型，用下面虚构内容测试：

   > 我们还没有批准上线。预算是 1200 USD，不是 12000 USD。请 Collie 先审核，暂时不要部署。

3. 生成候选后检查名字、否定、金额。接受只改变草稿，撤销恢复原文；接受后再手动编辑，撤销不应覆盖你的新编辑。
4. 生成过程中修改原文或丢弃候选，旧结果不能覆盖新的草稿。长于 3000 UTF-8 字节的文本应提示选取较短片段，不应默默截断。
5. Claude Code 仅在你主动选择并勾选本次云端处理后执行；本地安装的 CLI 不代表本地推理，可能使用已有账户额度。编辑原文、切换选项或生成一次后，同意状态应清除。
6. Codex 本轮只有安装版本检测，没有启用生成。不要把检测成功当成登录、余额或模型可用性检查。

不要用真实私人内容测试云端选项。数字和否定提示是保守检查，不能保证模型没有改错意思。详细边界见 [智能改写说明](../SMART-REWRITE.md)。

## 会议页与长语音

- 缩小窗口，打开一份有转录内容的测试会议：工具应换行、窄屏列表与详情应上下排列，录音停止条滚动后仍可达。
- 会议的清爽阅读版和原稿可以切换；保存与导出仍保留原稿。说话人改名按钮应能通过键盘到达。
- 英文试普通句子、技术名词、否定与自我修正；分别记录首次出现文字、松键到完成、是否重复 / 漏字。普通模式的后台预解码不会在录音中直接输入。
- 当前性能数字来自同机合成音频和内存收集器，不是实际设备 / 注入端到端指标。真实口音、轻声、背景声、回声、不同电脑还需要测试。
- 长时间不出现停顿的音频可能仍集中在松键后解码。本轮没有为了满足时间预算强行在连续人声中截断，也没有把模型原生推理改成可抢占取消。

发现问题时请记下应用名、语音语言 / 模型、是否启用渐进输入、操作顺序与大致时间；截图避免包含私人转录、账户或激活信息。先保留原始数据，不要反复重发或删历史。
