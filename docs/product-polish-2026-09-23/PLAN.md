## 范围和证据原则

- 按上下文将“visper blue / t”理解为 Wispr Flow / Typeless，已向用户说明。
- 官方文档、客户端静态资源、实际 UI 验证、推断分别标记；同名功能不默认跨平台一致。

- 本轮不发布、不推送、不覆盖当前安装，不自动开麦、录会、连接账号或改变个人词典。
- 不打断前台全屏应用。可用隔离的页面与离线/合成语音探针测试；无法执行的原生桌面验证要明确列为缺口。

## 工作流

1. **事实盘点**：两家官方帮助、发布记录、功能/平台区别、隐私/离线边界、本机版本和静态资源线索。
2. **VocalCode 差距**：当前已做、半完成、缺失、不适合照搬；关联真实用户痛点和最近 Fish 测试。
3. **常驻浮窗设计与实现**：非抢焦点、状态明确、可点击/键盘访问、停止/取消、安全交付、可隐藏、位置恢复与多显示器/DPI。
4. **质量与性能**：研究短分段丢失上下文；用保留的合成语音和额外回归评估正确性/响应时间，避免只优化一个样本或硬编码术语。真人录音需另行同意与人工标注。
5. **验证与交付**：Rust/前端合约/可行的原生烟测、构建；报告真实证据、范围、风险与下一步优先级。
