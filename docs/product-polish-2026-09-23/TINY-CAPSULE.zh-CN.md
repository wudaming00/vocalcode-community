## 过渡平滑（后续反馈）

原实现直接切换 HWND 大小及内容显隐，没有动画；收起宽限又由 180 ms 的常规主循环节奏唤醒，因此会突跳及额外等待。

- 原生几何改为 180 ms 展开 / 140 ms 收起的 cubic ease-out；反向从最后实际绘制位置继续，不先跳回终点。
- 仅动画期间按 16 ms 请求唤醒，结束即移除动画计时；离开宽限有独立截止时间，不额外等待一个 180 ms 周期。16 ms 是调度目标，不是低端硬件 / 游戏负载下的实测帧率保证。
- 菜单及底栏文字淡入；菜单内容使用固定最终尺寸，避免动画每一帧挤压换行；细胶囊入口补偿位置变化。
- 移动中的空闲功能按钮临时不可点击，入口可重新展开；真正录音 / 停止 / 取消状态跳过外观动画，避免延后停止操作。
- 保留操作系统减少动态效果选项，通过独立布尔握手同步；未知时保守禁用动画。
- 同一状态下不重建图标，避免每次状态 / 音量更新重置旋转动画。
- 隐藏原生布局扩至 14 例，包含展开 0 / 32 / 80 / 144 / 180 ms 的中间几何；浏览器预览检查悬停、离开和快速反向，均没有连接录音或调用模型。
- 全套测试第一次遇到两项既有会议测试在删除临时目录时发生 Windows 文件占用（OS 32）；这两项所在回归组顺序复跑通过。没有修改会议生产逻辑来掩盖清理问题。
