## 新增功能

| 功能 | 位置 | 默认 | 说明 |
| --- | --- | --- | --- |
| 语音换行 | 写作 → 语音命令 | 关 | "new line" / "new paragraph" / 换行 / 另起一段。英文按上下文排除 "add a new line" 这类名词用法；中文必须独立成句。 |
| 撤回上一句 | 同上 | 关 | "scratch that" / "strike that" / 删掉上一句。跟在逗号后撤回分句，跟在句号或换行后撤回整句。 |
| 口述列表 | 同上 | 关 | first/second/third、number one…、第一/第二/第三（可带 点/条/步）→ `1. …` 编号列表。 |
| 代码词 | 同上 | 关 | camel/pascal/snake/kebab/constant case、open paren、underscore、hashtag、question mark 等约 30 个符号。 |
| 说「回车」发送 | 同上 | 关 | 结尾 "press enter" / 回车 → 输入后在同一输入框按 Enter。前面是 to/and/you 等时视为普通文字。 |
| 风格 | 写作 → 风格 | 正式 | 正式 / 随意（去掉每行句末句号）/ 很随意（再小写普通句首词），可按程序名单独设置；一键把 15 个常见聊天软件设为随意。 |
| 试一试 | 写作页底部 | — | 打字模拟口述，走宿主真实 Rust 规则（IPC `writing_preview`），不是 JS 副本。 |
| 双击锁定免提 | 快捷键 → 按住说话模式 | 开 | 按住仍是按住说话；0.5 s 内快速双击进入免提，再按一次结束。单次轻点照旧什么都不做。 |
| 听写时静音其他声音 | 设置 → 常规 → 音频 | 关（仅 Windows） | 只静音**其他进程**当前在播放的会话，结束后只恢复自己静音的那些；会议录制时跳过；退出时阻塞恢复。 |
| Insights | 首页 | — | 连续天数、最长连续、每分钟字数（近 30 天、≥30 s 说话才显示）、本周字数、12 周热力图。`activity.json` 只存每天的次数 / 字数 / 说话毫秒数，不存文字。 |
| 翻译 / 自定义指令 | 历史 → 改写草稿 | — | 新增 翻译成英文 / 翻译成中文 / 自定义指令（≤400 字节，可直接口述）。仍是先预览、再接受、只复制，不替换其他程序里的文字。 |
| 多行投递 | 注入层 | — | 含换行 / Tab 的文字改走剪贴板粘贴（Windows 用 CRLF，保存并恢复原剪贴板）。之前 `\n` 会被敲成 Enter，聊天框里等于把半句话发出去。多行片段因此可以展开（结尾换行仍拒绝，防终端执行）。 |
| 历史复查 | 历史 | — | 被写作规则改过的条目显示「已应用格式规则: N · 清理前的识别结果」，可复制原文；历史行保留换行。 |

配置写在 `vocalcode.toml` 的独立 `[writing]` 表和两个顶层键（`double_tap_lock`、`mute_while_dictating`）。旧版本遇到未知键会忽略，所以回退旧 exe 不会读坏配置。

## 验证

**自动化**：全工作区 Rust 测试（legacy / community 两种配置）、两种配置 clippy `-D warnings`、`cargo fmt --check`、前端 10 个 node 合约测试文件、页面脚本 `node --check`。新增约 60 个测试，其中一批直接取自真实识别输出（见下）。

**真实模型回放**：`vocalcode-platform/examples/writing_replay.rs`，Windows 自带 TTS 生成中英文 WAV → 真实 SenseVoice → 生产引擎 + 全部写作规则 → 内存注入器。暴露出两个理想化假设并已修正：SenseVoice 英文在停顿处常常不打句号但会把下一句首字母大写；中文「删掉上一句」会被连到前一句上。

**装进本机真实使用**（legacy 1.3.1 身份，数据目录不变）：
- 通过 UI 自动化在真实窗口里操作并截图：写作页、试一试（英 / 中）、快捷键页、设置页、历史复查、首页 Insights、改写草稿的翻译与自定义指令。
- 真声学回路：扬声器播放 TTS → C920 麦克风 → 注入 X2（用户自己的说话键）→ 真实 App → 自建测试输入框。换行（多行粘贴）、删掉上一句、列表、回车发送、双击免提都在这条链路上跑通过；外放识别会偶尔听错（「换行」→「换」、「第三，」→「第三5」），属识别误差。
- 静音：另起进程播放不可闻的正弦波，按住说话时该会话 `GetMute()` = true，松开后恢复 false。
- 本地 Ollama `qwen2.5:7b-instruct`（CPU）：中译英保留 1200 / 12000 USD 与两处否定；自定义指令「改短一点，语气更友好」约 8 s 出候选。

实测中发现并修复的真 bug：写作页自己的中文示例「你好，换行，…。删掉上一句。…」会把问候语一起删掉（撤回先于换行执行，看不到换行边界）。

## 已知限制 / 没做的

- 规则是确定性的：说法必须接近列出的短语；识别错一个字就不会触发。Wispr 那种「actually 3 → 改成 3」的语义纠正需要语言模型，没有做。
- 按应用风格只认程序名，浏览器里的 Slack / Gmail 算同一个浏览器。
- 语音改写目前在草稿板里完成；「选中任意程序里的文字 + 快捷键 + 口述指令 + 原地替换」需要新的全局快捷键和跨程序替换，涉及输入钩子和焦点安全，未做。
- 静音只作用于默认播放设备上已经在播放的会话；听写开始后才开始播放的声音不会被静音。
- macOS：静音为空实现；其余规则是跨平台代码，但未在 Mac 上编译或实测。
